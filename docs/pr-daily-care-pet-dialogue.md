# PR 제목

feat: 가족 돌봄 자동 배정과 상태 기반 강아지 알림·대화

## 변경 내용

기존에는 가족이 돌봄 행동을 직접 골랐고 강아지의 기다림 문구가 실제 배정 상태와 연결되지 않았다. 이제 매일 한국 시간 오전 8시에 가족별 행동을 무작위 배정하며, 본인이 배정받은 행동을 실행하면 서버에서 완료를 저장한다.

미완료 담당자에 맞는 앱 내 팝업과 말풍선을 표시한다. 머리 위 느낌표를 누르면 오늘 돌봄 상태를 참고하는 Gemini 강아지 대화창을 연다. 기존 일기 분석과 일반 Mira 채팅 담당 범위는 변경하지 않는다.

## 검증 및 적용

- JavaScript 테스트 6개, Python API 테스트 8개, Flutter 테스트 14개 통과. Dart 정적 분석 이슈 없음.
- Firebase Auth/Functions/Firestore 에뮬레이터 연동 검증 통과: 동시 요청 8개, 동일 배정 유지, 본인 행동 완료, 중복 완료 방지, 비인가 접근·직접 쓰기 차단.
- 연동 테스트에서 발견한 Admin SDK FieldValue/FieldPath 접근 오류를 수정했다.
- Gemini 실제 응답 검증 통과: `/pet-chat` HTTP 200, 역할별 돌봄 문맥을 반영한 한국어 답변 수신. 실제 응답이 37.7~48.8초 걸려 기존 앱의 30초 제한을 초과하는 문제를 발견해 90초로 조정하고 대기 안내·오류 유형 구분을 추가했다.
- 클라우드 스케줄 실행은 아직 미검증이다. API 단위 테스트는 모델 호출을 모의 처리한다.
- 새 Cloud Functions와 Firestore 규칙, AI 서버, 앱을 함께 적용한다. 기존 직접 쓰기 방식의 구버전 앱은 새 규칙과 호환되지 않는다.
- 실행 명령과 상세 수용 기준: [daily-care-pet-dialogue.md](daily-care-pet-dialogue.md).
